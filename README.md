# 출판사 재주문 예측과 고객 분석

컴퓨터·AI 교육 도서 출판사 마린북스(온에듀)와 함께한 기업 연계 프로젝트의 분석 코드입니다. 주력 분야는 컴퓨터 교육(OA 활용·자격증 대비), 코딩·AI 교육, 아동 창작 활동서입니다.
출판사가 서점(교보문고·예스24) 협력사 시스템(SCM)에서 볼 수 있는 입하·반품·판매·구매자 집계 자료로, 한정된 재고와 마케팅 자원을 어느 도서에 먼저 쓸지 정하는 근거를 만듭니다.

> 협력사 제공 자료와 분석 결과는 저장소에 포함하지 않습니다. 코드는 자료가 없으면 실행되지 않으며, 테스트는 작은 가상 데이터로 동작합니다.

## 문제 정의

- 본 목표: 매월 1일 기준으로, 다음 30일 안에 서점이 재주문할 도서 상위 20%를 고릅니다(재고 준비·중쇄 판단).
- 비교 전략: 무작위 / 최근 판매 규칙 / 예측 모델(로지스틱 회귀, 그래디언트 부스팅)
- 평가 지표: Precision·Recall·Lift@20%, PR-AUC, ROC-AUC, 누적 이득 곡선
- 예측 시점 통제: 변수는 기준일 이전 기록만 쓰고, 기준일 이후 30일은 라벨에만 씁니다. 기준일 이후 값을 바꿔도 변수가 변하지 않는지 테스트합니다.
- 데이터 품질: ISO/IEC 25012의 완전성·일관성·추적성 관점을 참고한 자체 점검 규칙을 씁니다(적합성 인증 아님). 점검 미적용/적용 두 조건을 같은 평가 대상·같은 정답으로 비교합니다.

## 구성

```
교보/코드/
├─ kyobo.py                     서점 SCM 자료 → 품질 점검 → 도서×월 변수 → 재주문 예측·평가 → HTML 보고서
├─ common.py                    지표, 모델, RFM 세분화, 규칙 기반 검증기, 보고서 틀
├─ publisher.py                 출판사 내부 거래처 장부용(거래처×도서 재주문, 거래처 세분화)
├─ make_synthetic_publisher.py  거래처 장부 형식 검증용 합성 데이터 생성
├─ crm_roi.py                   ROI·CRM 보조 분석
└─ test_*.py                    단위 테스트
```

## ROI·CRM (보조 분석)

`교보/코드/crm_roi.py`
- ROI 1 반품 위험 도서 예측과 대응 시 절감액(비용 가정 조합별 범위로 보고)
- ROI 2 광고 손익분기: 권당 공헌이익(정가×공급율 − 제작원가·인세·물류 가정)으로 본전이 되는 판매 증가율과 허용 광고비 계산. 광고 효과 자체는 추정하지 않음
- ROI 3 무작위 판촉 실험 설계(층화 배정, 검출 가능한 효과 크기)
- CRM 구매자 성별·연령·지역 집계로 독자 페르소나, 독자 구성이 비슷한 도서 추천, 6개월 구간별 독자층 변화. 개인 단위가 아닌 집계 자료이며, 한 연령 구간에 구매가 몰린 경우(대량 구매 의심)와 미기록 구간을 품질 메모로 표시

비용 값은 모두 `ASSUMPTIONS`에 모아 둔 가정입니다.

## SQL 데이터 계층

`교보/코드/sql_layer.py`, `교보/코드/sql/`
- `schema.sql` 테이블(도서, 입하, 반품, 월별 판매, 구매자 구성, 원본 파일 해시)
- `quality_checks.sql` 품질 점검 규칙(규칙 하나 = 쿼리 하나)
- `features.sql` 기준일 변수(`일자 < :cutoff`로 정보 누출 방지)
- `views.sql` 품질 플래그·정제 뷰와 출판사용 월간 지표(재주문·반품·판매, 반품 사유, 시리즈 판매, 구간별 구매자)
- `agent_queries.sql` LLM Agent·검증기용 읽기 전용 근거 조회

`test_sql_layer.py`가 SQL 결과와 Python(pandas) 결과가 같은지 대조합니다(자료가 없으면 건너뜀).

## 공개 데이터 확장 실험

출판사가 보유하지 않은 개인 고객·판촉 데이터를 모은다면 무엇이 가능한지 공개 데이터로 실험합니다. 회사 자료 결과와 섞지 않습니다. → `교보/공개데이터/README.md`

## 두 번째 서점에 같은 절차 적용

`예스24/코드/yes24.py`는 예스24 SCM 자료를 교보와 같은 형식으로 읽기만 하고, 품질 점검·예측·평가·ROI·CRM은 `교보/코드/`를 그대로 씁니다.
- 재주문 = 실제 발주(교보는 발주 이력이 없어 입하로 대신함)
- 구매자 = 월별 판매에 포함된 성별·연령·지역 수치를 교보와 같은 6개월 구간 형식으로 변환

## 오류 삽입 실험

`오류실험/코드/error_injection.py`는 원자료에 정답을 아는 오류 6종을 0~20% 넣습니다. 그 뒤 품질 점검이 재주문 예측을 지키는지 시드 10개로 반복해 비교합니다. 점검 규칙은 기존 것을 그대로 쓰고, 평가 정답은 원자료에서 만듭니다. → `오류실험/README.md`

## LLM 멀티 에이전트 검토

`에이전트/코드/`는 분석가 A·B의 독립 분석, 조정자의 토론 조정, 적대적 검토자의 반박을 거쳐 정제 조치를 정합니다. 에이전트는 원본 행 없이 집계 도구 결과만 보고, 근거 ID 없는 조치는 버립니다. 품질 점검 유무 × 에이전트 검토 유무(A/B/C/D)를 오류 삽입 자료에서 비교합니다. → `에이전트/README.md`

`에이전트/코드/knowledge.py`는 도서 지식 에이전트입니다. 도서 제목으로 대비 시험·주제·시리즈를 분류하고(분류가 A·B 독립 → 판정), 자격시험 시행 월을 웹에서 출처와 함께 찾습니다. 이 지식으로 만든 변수(도서 종류, 같은 종류의 지난해 같은 달 재주문률)를 개선 공정에서 씁니다.

진행 중 생긴 문제와 해결 과정(증상·원인·조치·배운 점)은 `트러블슈팅.md`에 기록합니다.

## 결과 요약 (가명화)

출판사 자료로 얻은 결과를 요약했습니다. 원자료와 정확한 판매량·건수는 싣지 않고 비율은 반올림했습니다. 평가는 두 서점 모두 마지막 6개월(매월 대상 도서의 20% 선정)입니다.

### 본 목표: 다음 30일 재주문 도서 선정 (Precision@20%)

| 전략 | 교보문고 (재주문 = 입하) | 예스24 (재주문 = 발주) |
|---|---|---|
| 예측 모델 (검증 구간에서 선택) | 약 52% | 약 59% |
| 최근 3개월 판매 규칙 | 약 42% | 약 47% |
| 무작위 | 약 25% | 약 32% |

- 두 서점 모두 모델이 판매 규칙보다 약 10%p, 무작위보다 약 1.8~2.1배 높았습니다. 같은 절차가 서점이 바뀌어도 통했습니다.
- 추가 품질 점검 적용 여부에 따른 예측 성능 차이는 거의 없었습니다(±1%p).
  - 그래도 예스24 자료에서는 수량이 0인 발주 행(약 28%)을 걸러냈습니다. 이 점검이 없으면 이 행들이 "재주문"으로 잘못 세어집니다.
  - 교보문고 자료에서는 출간 전 입하, 판매 수량 음수(반품 상계), 구매자 성별·연령이 전부 미기록인 반기, 한 연령 구간에 구매가 몰린 대량 구매 의심 사례를 찾아 표시했습니다.

### 오류 삽입 실험

- 점검 규칙은 의도한 오류 3종(수량 0·중복·ISBN 오타)을 모두 잡았습니다. 단위 오류·날짜 오기·행 누락·판매 중복은 하나도 잡지 못했습니다.
- 오류를 20% 섞으면 모델 성능이 약 2~5%p 떨어졌습니다. 점검 유무에 따른 차이는 시드 간 흔들림(약 2%p) 안이었습니다.
- 행 단위 규칙이 놓치는 오류 유형은 다음 단계인 LLM Agent 검토의 평가 정답지로 씁니다.

### ROI (비용은 가정값, 범위로 보고)

- 반품 대응: 반품 규모가 작아서 위험 도서에 따로 대응하면 대응 비용이 절감액보다 큽니다. 반품을 사후에 관리하기보다 재주문 예측으로 공급량을 맞추는 편이 낫습니다.
- 광고 손익분기
  - 도서 한 종 단위로 광고하면 본전이 어렵습니다. 판매 30% 증가를 가정해도 도서당 허용 광고비가 월 1만 원 미만입니다.
  - 30여 종 규모의 주력 시리즈로 묶으면 월 10만 원 광고는 판매가 약 22~27% 늘면 본전입니다.
- 광고 집행 기록: 두 서점 모두 유료 광고 집행 기록이 없었습니다. 그래서 광고 효과는 추정하지 않고 무작위 판촉 실험을 설계했습니다.

### CRM (서점 구매자 집계, 개인 단위 아님)

- 분야: 판매의 약 4분의 3이 컴퓨터 분야(OA·자격증, 코딩·AI 교육)이고, 나머지는 아동 창작 활동서가 대부분입니다.
- 구매층: 주 구매층은 40대 여성입니다. 성별이 확인된 구매 중 여성이 약 80%이고, 연령이 확인된 구매 중 40대가 약 50~65%입니다. 어린이·청소년 대상의 컴퓨터·AI 교육 도서라 구매자(학부모)와 사용자(아동·학생)가 다릅니다. 메시지와 채널은 학부모 기준으로 잡아야 한다는 근거가 됩니다.
- 서점별 차이: 예스24는 10세 미만 명의 구매가 약 25%로 교보문고보다 높았습니다.
- 지역: 두 서점 모두 영남권 구매 비중이 가장 컸습니다(교보문고는 대구가 약 3분의 1, 예스24는 경상도가 약 43%).
- 추이: 6개월 구간별 독자층은 2021~2026년 동안 40대 여성 중심으로 유지되었습니다.

### 공개 데이터 확장 실험

- 판촉 메일 효과 (Hillstrom 무작위 실험)
  - 메일을 보내면 구매 전환이 +0.3~0.7%p 늘었습니다.
  - 출판사의 권당 이익을 대입하면 메시지 한 건 비용이 약 18원 이하여야 본전입니다.
- 추천 방식 비교 (Book-Crossing): 상위 10권 적중률은 아래와 같습니다. 출판사가 개인 구매 이력을 모으면 추천 성능이 크게 오를 수 있다는 근거입니다.

  | 추천 방식 | 적중률 |
  |---|---|
  | 연령대 집계 기반 추천 (현재 출판사 자료 수준) | 약 14% |
  | 개인 이력 기반 협업 필터링 | 약 30% |
